## 0.5.2 更新说明（可复制）

安全更新：加强网页笔记界面隔离，阻止网页脚本读取或篡改当前页笔记，以及通过伪造点击、双击或快捷键执行笔记操作。正常编辑、Ctrl/Command+Enter 保存、图片笔记和同步功能保持可用。已有笔记无需迁移，权限和数据用途未增加。

可选模型服务继续要求远程接口使用 HTTPS，仅本机回环地址允许 HTTP。配套 Obsidian 插件 0.5.2 也补齐了这一限制；该插件需单独升级，不包含在 Chrome 商店 ZIP 中。

### 详细说明（以下内容可直接复制）

读到想记住的一句话，选中文字就能划线、写下批注。划线笔记帮助你把网页阅读中的摘录与想法保存下来，回到同一篇文章时继续阅读和思考。

主要功能
• 网页划线与批注：选择文字、使用不同颜色标记，刷新后恢复划线。
• 文章笔记与图片笔记：在当前网页侧栏查看摘录，记录整篇文章的想法，保存图片及说明。
• 本地优先：笔记先保存在当前浏览器，无需注册账号，也无需安装 Obsidian。支持 JSON 备份与恢复。
• 本地 Markdown：选择并授权文件夹后，将资料写入 Markdown、JSON 和图片文件，可配合 Obsidian 使用；支持同步卡片批注。
• 可选 flomo / 思源笔记：自行配置后，把新增或修改的笔记写入所选服务。flomo 修改会追加新记录；思源修改会追加更新版本。浏览器删除不会删除这些服务中的副本。
• 可选阅读记录：默认关闭。开启并保存后，在可识别文章页前台活跃约 15 秒时，记录文章地址、标题、正文、阅读日期、活跃时长和滚动进度。可关闭或排除指定网站。
• 可选 AI 标签：默认关闭。连接 Obsidian 导出的标签文件并配置模型接口后，从已有标签中为笔记选择标签。

数据与隐私
网页正文、摘录、图片和批注保存在本机。开发者不接收你的笔记，不提供广告或使用分析。启用 flomo、思源或模型接口时，相应内容会发送到你选择的服务：flomo 接收笔记及原图链接，思源还可接收图片文件；模型接收有长度限制的标题、批注、摘录以及已有标签名称。全文和自动阅读会话不发送至这些服务。请阅读隐私政策及设置中的数据说明。

使用说明
安装后在普通 HTTP/HTTPS 网页选择文字开始划线，点击工具栏中的扩展图标打开当前网页笔记。Chrome 内部页面、扩展商店等浏览器受保护页面不支持注入划线界面。PDF 浏览器内置查看器不在本扩展支持范围内。第三方同步需自行配置；flomo API 需相应会员权限，模型调用费用由服务商决定。

## 隐私权做法（后台填写）

### 单一用途

帮助用户在网页阅读时保存、批注和找回阅读笔记，并将用户选择的笔记写入本地文件夹或自行配置的笔记服务。阅读记录与已有标签整理用于同一阅读笔记用途。

### 权限说明

| 字段 | 可复制内容 |
| --- | --- |
| unlimitedStorage | 文章正文、图片附件、划线、批注及用户启用的阅读记录保存在本机 IndexedDB。长期积累的正文和图片可能超过普通存储配额，因此需要 unlimitedStorage。 |
| alarms | 每分钟处理待写入笔记、同步已授权文件夹中的批注修改，并重试用户配置的 flomo 或思源写入任务。 |
| 网站访问权限 | 扩展支持任意普通 HTTP/HTTPS 网页上的划线批注，需要在页面加载时恢复已保存标记，并在用户开启阅读记录后记录文章阅读。保存图片需要访问可能位于不同域名的原图；可选同步和标签功能访问用户配置的服务地址。activeTab 仅在点击后短暂授权，无法实现再次访问网页时自动恢复划线。无痕模式禁用，可在设置中排除网站。 |
| 远程代码 | 选择「否」。全部 JavaScript 与依赖随包提供。远程 API 仅返回数据，模型返回的 JSON 标签只与已知标签匹配，不作为代码执行。 |

### 数据类型

本地处理也属于需要披露的数据处理，不能选择「不收集任何数据」。按当前源码，勾选以下类型；以后台字段定义核对名称：

| 类型 | 原因 |
| --- | --- |
| 网站内容（Website content） | 正文、摘录、图片、批注、文章笔记和标签 |
| 网络记录 / 浏览记录（Web history） | 当前文章 URL、标题和记录日期；未使用 chrome.history 读取完整浏览器历史 |
| 用户活动（User activity） | 用户开启阅读记录后的前台活跃时长、近期交互和滚动进度；不采集输入的按键内容 |
| 身份验证信息（Authentication information） | 用户自行填写的 flomo API URL、思源 Token、模型 API Key；仅保存在本机，用于访问用户指定服务，不进入备份或网页消息 |

扩展没有专门采集身份、健康、财务、位置或私人通信的功能；用户自行摘录的网页内容可能包含敏感内容，并按网站内容同样处理。如以后新增相应专门功能，需重新检查分类。

代码行为支持勾选三项数据用途认证：不出售或转移数据用于未经允许的用途；不用于与单一用途无关的目的；不用于确定信用或放贷资格。发布者需阅读后台原文，并由账号所有者作出真实声明。

## 审核测试说明（可复制）

Chrome 120+。核心功能无需登录、测试账号、Obsidian 或任何付费服务。

1. 安装后打开设置页，阅读隐私说明。自动阅读和 AI 标签默认关闭。
2. 打开普通文章，例如 https://developer.chrome.com/docs/webstore/publish 。选择正文一句话，点击黄色划线或「记笔记」，填写并保存批注。
3. 点击扩展图标，查看当前文章侧栏中的摘录。填写文章笔记；刷新网页检查划线恢复。
4. 在设置页下载 JSON 备份。自动阅读未开启时不应有阅读会话。
5. 在设置页「阅读记录」开启「自动记录阅读」并点击「保存设置」。返回文章、刷新、在前台阅读超过 15 秒，再导出备份检查 sessions。关闭后停止新记录；排除域名后该站划线与阅读记录均停用。
6. 可选本地写入：选择空的测试文件夹并授权，保存笔记，点击「立即同步笔记」，检查 Reading/Cards/ Markdown。此步骤无需 Obsidian。
7. 可选 flomo：使用审核者自己的有效 flomo API URL，保存写入设置后新增批注，检查 flomo 新记录。需要相应 flomo API 权限。
8. 可选思源：运行思源桌面版（项目验收基线 3.8.10），填本机 http://127.0.0.1:6806 与自己的 Token，测试连接、选择笔记本并保存。新增文字/图片笔记，检查思源「划线笔记」下生成的文档。
9. 可选 AI：在所选笔记资料文件夹中放置 Data/vault-tags.json，内容为 {"schemaVersion":1,"source":"obsidian-vault","tags":["阅读","写作"]}（正常使用由配套 Obsidian 插件导出）。配置自己的 HTTPS OpenAI 兼容 Chat Completions 服务、Key 和模型，开启后保存笔记；只会从已有标签中选择。也可使用本机 HTTP 服务；无需开发者提供账号。

第三方请求按设置项说明发送数据，未配置则不请求。请勿在审核备注中粘贴真实 API Key。若审核方要求可直接使用的第三方测试凭据，需要发布者另行提供隔离测试账号。
