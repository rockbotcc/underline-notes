# Chrome Web Store 首次发布 · 0.2.0

## 商店详情

名称和简短说明由安装包清单提供。默认语言选简体中文，建议类别为「工具」中的工作效率相关类别，以后台实际选项为准。

**详细说明（复制下列三段）**

读到想记住的一句话，选中文字就能划线、写下批注。下次回到同一篇文章，划线会在原文中显示。点击工具栏里的「划线笔记」，可以一起查看当前网页的摘录、图片笔记和整篇文章的想法。

开启阅读记录后，扩展会在可识别的文章页前台活跃约 15 秒时，自动保存文章、阅读时长和进度。此功能默认开启，可以在设置中关闭，或排除指定网站。资料保存在当前浏览器中，可以导出 JSON 备份并在之后恢复。

想把摘录带回自己的笔记库时，在设置页选择本地文件夹。扩展会将摘录、批注和文章写为 Markdown，并同步对卡片批注的修改。可以选择 Obsidian 仓库，也可以使用普通文件夹。网页划线和批注无需注册账号。

## 隐私权做法

**单一用途**　帮助读者在网页上记录、找回自己的阅读笔记，并将这些资料保存到自己选择的本地笔记库。

| 后台字段 | 填写内容 |
| --- | --- |
| unlimitedStorage | 文章正文、图片附件和阅读笔记存储在本机 IndexedDB 中。长期保存多篇文章及图片可能超过常规配额。 |
| alarms | 每分钟检查已授权的本地笔记文件夹，写入待处理修改，并读回在本地 Markdown 卡片上修改的批注。 |
| 网站访问权限 | 用户可在任意普通 HTTP/HTTPS 文章页上划线。内容脚本需要在页面加载时恢复标记并按设置记录阅读；用户保存图片时，后台需要从图片所在站点下载原图，该站点可能与文章站点不同。 |
| 远程代码 | 选「否」。扩展逻辑与依赖随安装包提供。图片请求的结果作为图片数据处理。 |

**数据使用说明**　扩展在本机处理网页浏览记录（文章地址、标题、日期）、用户活动（活跃时长和滚动进度）及网站内容（正文、摘录、图片和批注）。这些资料仅用于阅读笔记功能。用户发起的图片下载会访问原图服务器，可能携带该站点的凭据。若表单专指向设备外收集的数据，应按后台对该字段的定义填写，并与公开隐私政策核对。发布者需自行核实并完成后台针对销售、限定用途和信用评估的声明。

## 测试说明（可复制到审核备注）

使用 Chrome 120 或更高版本。无需登录，无需安装 Obsidian。打开一篇普通 HTTPS 文章（如 https://developer.chrome.com/docs/webstore/publish ），选择正文中一句话，点击黄色划线。点击浏览器工具栏中的扩展图标，在侧栏找到摘录，添加并保存笔记。刷新网页，可再次看到划线并打开批注。

在扩展设置中关闭「自动记录阅读」并保存，手动划线仍可使用。要验证本地导出，请选择一个空的测试文件夹并授权，点击「立即同步笔记」，检查 Reading/Cards/ 中的 Markdown 文件。卸载前可从设置页导出备份。
