# 思源卡片盒插件方案

日期：2026-11-13。用户确认首版范围：卡片流、搜索筛选、补写想法。

## 形态与分工

采用思源官方前端插件机制，安装在工作空间 `data/plugins/underline-notes/`。通过顶部图标或命令打开独立卡片盒页签。Chrome 扩展继续负责网页采集和持久写入队列，思源插件负责本机回顾与补写。

官方依据：[插件模板](https://github.com/siyuan-note/plugin-sample)、[插件 SDK](https://github.com/siyuan-note/petal)、[3.8.10 内核 API](https://github.com/siyuan-note/siyuan/blob/v3.8.10/docs/API.md)。使用 SDK 1.3.0 类型，最低兼容版本固定为本地验收版本 3.8.10，不宣称旧版兼容。

## 数据与展示

- 每条浏览器摘录对应一个思源原生文档，每次内容变化追加一个带 `custom-underline-hash` 的版本块。
- 插件分页查询这些属性所在的块；按文档聚合，按版本标题中的 ISO 时间选择最新版本。旧版本仍在文档中，不加入最新卡片的搜索范围。
- 卡片使用原生 Protyle 只读展示，保留 Markdown 格式。初始展示 30 张，可加载更多。加载失败展示错误，保留已有卡片。
- 搜索标题、最新内容和插件补写想法；多个关键词取交集。标签来自内容中的 `#标签`，父标签匹配子级，支持笔记本筛选。关键词不进入 SQL。
- 「查看来源」只接受 HTTP(S) 链接；「打开文档」通过原生页签显示完整文档。

## 补写与失败恢复

补写内容追加为独立原生超级块，标记 `custom-underline-thought`。不改写浏览器版本，也不覆盖任何其他原生块。

保存前先持久化草稿、随机块 ID、内容签名及发送快照。重试会先读取目标文档，检查同一属性块内的 ID 和签名。追加成功但响应丢失时复用同一身份，避免重复内容；无法确认时保留草稿，并锁定该次发送内容，提示重试。

插件草稿保存在 `data/storage/petal/underline-notes/drafts.json`。文件读写有超时及结果检查，保存草稿失败时不继续追加原生内容。首版针对单个活跃客户端；不支持多个思源窗口/设备同时编辑同一份插件草稿。

外部变化时提示刷新；刷新、筛选和切换标签保留草稿。插件卸载后原生文档与已提交想法仍可正常阅读。

## 首版边界

支持桌面客户端及桌面浏览器。暂不实现移动端卡片盒、AI 打标、附件上传、任意思源文档自动导入和双向编辑浏览器摘录。普通编辑器手动新增的无标记块保留在原文档，但不纳入卡片搜索；在带标记的想法块内编辑的内容会在刷新后更新。

浏览器连接思源仍需要地址、API Token 和目标笔记本；插件运行于思源当前会话，不增加第二套 Token 设置。插件在发布服务中默认禁用。

## 工程交付

源码位于 `siyuan/`；构建输出 `dist-siyuan/underline-notes/`，发布脚本生成 `dist-release/underline-notes-siyuan.zip`。与 Chrome 和 Obsidian 共用版本号，发布前校验一致性。安装包包含许可证和 NOTICE。

测试包括数据分组/搜索/标签、标记注入隔离、保存失败与响应丢失恢复，以及独立官方内核和真实思源前端中的插件加载、展示、草稿恢复、保存和打开文档。所有自动化数据仅写入临时工作空间。


## 界面对齐（2026-11-13）

根据用户要求，思源插件在构建时复用 `obsidian/styles.css`，通过 CSS scope 限定在本插件根元素内；`siyuan/styles.css` 只维护原生预览、明暗主题和宿主适配。两端共用品牌、字体层级、配色、卡片宽度、导航和标签树样式。

操作统一为卡片右上角「更多操作」菜单、双击补写、⌘/Ctrl + Enter 保存，以及 Esc 收起并保留草稿。思源仍使用原生只读预览，按批注、补写、摘录、来源组织展示；隐藏同步标题和生成时间仅影响视图，不改变原生数据。

首轮对齐仅覆盖已有能力；随手记和每日回顾的后续实现见下节。阅读足迹不展示无效入口。菜单支持方向键与 Escape，关闭后还原焦点；标签树支持独立折叠。

## 随手记与每日回顾（2026-11-13）

随手记复用 Obsidian 顶部输入框、记录按钮、手写标签及 ⌘/Ctrl + Enter。由用户选择已打开的笔记本，单笔记本时自动选中；目标记忆与草稿存储于 `quick-note.json`。每条随手记通过 `createDocByParent` 创建独立原生文档，内容超级块标记为 `custom-underline-local`，与摘录一起进入卡片流、搜索和标签树。

创建前持久化文档 ID、块 ID、内容摘要和不可变发送快照。响应丢失后读取原文档核对相同身份，失败不清空草稿；已有同 ID 文档内容不匹配时停止，不覆盖。插件初始化无法读取草稿时显示错误，不把网络错误当作空草稿。数据共享方式沿用单个活跃客户端限制。

每日回顾与 Obsidian 共用 `shared/review.ts` 的日期与卡片 ID 排序逻辑，每天从筛选范围稳定选取最多 8 张，提供进度、上一张、下一张、补写、完成与返回。切换搜索或笔记本后从新范围重新开始；不持久化完成进度，不引入间隔记忆或提醒。
