笔记写入位置

笔记先保存在浏览器，再写入你选择的位置。

在「划线笔记」下按条保存。修改已发送笔记会追加更新版本，保留思源中的补写；删除浏览器记录不会删除思源文档。图片自动保存为思源附件并显示在正文中，全文和阅读日志保留在浏览器。需要支持结构化文档 API 的思源版本（验收基线 3.8.10）。

按已保存的思源配置批量补传，保留原文档及补写；本地没有图片文件时会尝试下载原图。已完成的图片不会重复追加。

保存后，新增或修改的划线、批注和文章笔记会发送到 flomo；已有笔记不会批量补发。每次修改会追加新记录，删除和 flomo 内的修改不会反向同步。图片以原图链接写入，全文与阅读记录仍保存在浏览器。API URL 仅保存在本机，不包含在资料备份中。

大模型自动标签

保存划线或笔记时，从整个 Obsidian 仓库的已有标签中选择，最多添加三个，不创建未知标签。

从已连接目录的 Data/vault-tags.json 读取全仓库标签（正文 #标签及 YAML tags），不使用浏览器笔记或 flomo 标签库。Obsidian 关闭时使用最后导出的列表。开启后发送当前标题（最多 200 字）、批注（1800 字）、摘录（1200 字）和仓库标签名到所配置的服务。API Key 仅保存在本机，不进入备份或网页。标签追加到批注并随笔记同步；读取标签或模型调用失败时仍保存原笔记。

阅读记录

使用本地 Obsidian 时，读过的文章会按天整理为 Markdown 阅读日志；flomo 和思源不接收自动阅读记录。

你的资料，随时带走

备份包含浏览器收集的正文、划线、笔记和阅读会话。恢复时按 ID 合并，保留较新版本。

Obsidian 中补写的“延伸思考”请随仓库一起备份。卸载扩展会清除浏览器内的数据。

每条划线和文章笔记写入 Cards/，正文写入 Articles/。卡片盒和每日回顾会直接展开卡片。

在 Obsidian 中点击“编辑笔记”修改“我的批注”，浏览器运行且文件夹授权有效时会自动同步，通常每分钟检查一次，也可立即同步。两边修改冲突时保留版本并提示合并。摘录和来源是引用材料；旧“延伸思考”和随手记仍仅保存在 Obsidian。
