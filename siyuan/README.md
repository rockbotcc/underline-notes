# 划线笔记 · 思源插件

在思源中浏览网页摘录、搜索文字、按笔记本与多级标签筛选，补写自己的想法，使用随手记和每日回顾。

## 安装

需要思源 3.8.10 或更新版本；第一版支持桌面端和桌面浏览器。

1. 将插件文件夹 `underline-notes` 放入工作空间的 `data/plugins/`。
   源码安装先在项目根目录运行 `npm ci`、`npm run build`，取 `dist-siyuan/underline-notes/`；当前尚未发布到集市。
2. 在思源「设置 → 集市 → 已下载 → 插件」中启用「划线笔记」。首次使用插件时按思源提示确认信任；如未出现，核对 `data/plugins/underline-notes/plugin.json` 层级并重启思源。
3. 点击顶部「划线笔记 · 卡片盒」按钮，或通过命令面板打开卡片盒。

浏览器采集仍由划线笔记 Chrome 扩展完成。在扩展设置中选择「思源笔记」，配置本机地址、API Token 和目标笔记本，再保存摘录。

## 使用

- 卡片盒读取当前工作空间中已打开笔记本内、由划线笔记写入的卡片。普通文档不会自动导入。
- 每张卡片显示最新同步版本。历史版本保留在原生文档中，点击「打开文档」查看。
- 搜索覆盖标题、最新摘录和插件补写的想法；空格分隔多个词时需要同时匹配。支持 `#标签` 和 `#标签/子标签`，父标签包含所有子标签。
- 「补写想法」将 Markdown 追加为独立原生块。浏览器后续同步保留这些内容。普通文档编辑器中新增的无标记块仍保留，但不纳入本版卡片搜索。
- 未保存草稿存储在插件数据中。保存异常后点击「重试保存」；插件会核对原文档，避免网络响应丢失造成重复追加。
- 外部修改后显示刷新提示；点击「刷新」更新卡片。编辑中的草稿会保留。

- 随手记：在顶部输入框写想法，选择保存笔记本，点击「记录」或按 ⌘/Ctrl + Enter；每条生成独立原生文档。目标笔记本会记住，草稿重载后恢复。失败时使用「重试记录」核对结果，避免重复创建。
- 每日回顾：从当前关键词、标签和笔记本筛选范围，每天稳定选取最多 8 张卡；使用上一张、下一张、补写想法、完成回顾和回到卡片。选卡逻辑与 Obsidian 共用，不持久化完成进度，不含推送提醒或间隔记忆。

## 与 Obsidian 一致的卡片盒体验

- 使用同一份卡片盒样式：绿色主题、左侧统计和标签导航、固定阅读宽度与日期栏；跟随思源的明暗主题。
- 点击标签或父级分类筛选，点击折叠箭头展开/收起子标签。笔记本筛选与刷新位于搜索栏下方。
- 卡片按批注、补写想法、摘录、来源排列，隐藏重复标题及同步元数据；原生文档完整保留。
- 点击右上角「… → 补写想法」或双击卡片进入编辑。⌘/Ctrl + Enter 保存；Esc 或「收起」关闭编辑区并保留草稿。
- 「… → 打开」进入完整原生文档；来源标题跳转原网页。阅读状态不常驻编辑按钮。

思源版暂未加入按来源聚合、阅读足迹和 AI 自动标签入口。

## 数据与边界

不依赖云端服务，不调用 AI，不需要在插件内填写 API Token。插件通过当前思源会话调用本机内核；只读取带有划线笔记标记的卡片，按用户操作创建随手记文档或追加想法。草稿、目标笔记本及待核对写入身份保存在 `data/storage/petal/underline-notes/`；首版仅支持单个活跃客户端编辑插件草稿。

第一版没有双向编辑、附件上传、自动标签、移动端卡片盒。图片摘录仍是原图链接。卸载插件不会删除原生卡片或已保存想法。

升级前停用插件并备份旧插件目录，复制新文件后启用，关闭旧卡片盒页签再打开。不要覆盖 `data/storage/petal/underline-notes/`。
