新增 flomo 写入：在扩展设置中选择 flomo，填写专属 API URL，新增或修改的划线、批注和文章笔记即可按条写入。

- 默认标签按来源网站分组，例如 `#划线笔记/example.com`；域名不包含路径、参数和端口。
- 记录按「自己的笔记 → 引用摘录 → 文章标题及标签 → 来源 URL」紧凑排列，图片保存原图链接和说明。
- 写入队列支持失败重试和相同内容去重，设置页及网页侧栏显示写入状态。
- 保留默认本地 Obsidian 输出，可切换写入位置；flomo API URL 仅保存在本机，不进入资料备份。
- 改进笔记界面，避免卡片重复显示手写标签；补充安装指引及开发时共用构建、安装目录的说明。

flomo 写入采用单向追加：修改已发送笔记会新增记录，已有笔记不会自动批量补发；删除和 flomo 内的修改不会反向同步。全文、图片文件和自动阅读记录仍保存在浏览器。

下载 `underline-notes-chrome.zip` 安装 Chrome 扩展；使用 Obsidian 卡片盒时下载 `underline-notes-obsidian.zip`。另外提供 Obsidian 更新所需的 `main.js`、`manifest.json`、`styles.css`，以及 `SHA256SUMS.txt` 校验文件。

升级请覆盖原安装目录，在 `chrome://extensions` 重新加载原扩展并刷新网页，以保留扩展身份和已有数据。域名标签用于新写入的记录，不会修改已存在的 flomo 记录。
