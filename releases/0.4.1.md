- 采用 Apache License 2.0，版权署名为 rockbotcc；仓库新增 `LICENSE` 和 `NOTICE`。
- Chrome 和 Obsidian 安装 ZIP 均包含 `LICENSE`、`NOTICE`。Chrome 包另附第三方依赖许可证；Obsidian 独立更新使用的 `main.js` 内嵌完整许可证和 NOTICE。
- README 提供本地保存、写入 flomo 两种 Codex 安装提示；安装指南按写入位置分别配置和验证，flomo 无需本地笔记文件夹或 Obsidian。

- 修复笔记编辑时键盘事件触发网页快捷键的问题。

下载 `underline-notes-chrome.zip` 安装 Chrome 扩展；使用 Obsidian 卡片盒时下载 `underline-notes-obsidian.zip`。另外提供 Obsidian 更新文件 `main.js`、`manifest.json`、`styles.css`，独立的 `LICENSE`、`NOTICE`，以及 `SHA256SUMS.txt` 校验文件。

升级时覆盖原 Chrome 扩展安装目录，在 `chrome://extensions` 重新加载原扩展并刷新网页，以保留扩展身份和已有数据。Obsidian 插件更新时保留已有 `data.json` 和其他用户文件，并一并复制随包提供的许可证与署名文件。已有笔记和写入设置继续保留。
