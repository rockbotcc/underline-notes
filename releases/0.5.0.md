本次更新新增思源笔记输出和配套卡片盒插件，可在思源中浏览摘录、记录随手记与每日回顾。

- **Chrome 写入思源**：配置地址、API Token 和目标笔记本后，每条摘录写入独立原生文档；修改追加版本，保留思源补写。支持离线队列、重试去重和缺失文档恢复。
- **思源卡片盒**：与 Obsidian 共用卡片盒样式，支持搜索、多级标签和笔记本筛选、补写想法、快捷键保存、打开原生文档及明暗主题。
- **随手记**：顶部输入框记录独立想法，记住目标笔记本；草稿可恢复，响应丢失时核对已写入内容，避免重复创建。
- **每日回顾**：与 Obsidian 共用选卡逻辑，每天从当前筛选范围稳定选取最多 8 张，支持翻页、补写和完成返回。
- 修复从原生文档返回卡片盒时重复打开标签页的问题。README 和安装指南增加思源发布包下载、安装及升级说明。

## 下载与安装

- [思源插件 ZIP](https://github.com/rockbotcc/underline-notes/releases/download/0.5.0/underline-notes-siyuan.zip)：思源 3.8.10+，解压后把整个 `underline-notes/` 文件夹放入工作空间的 `data/plugins/`，在「设置 → 集市 → 已下载 → 插件」启用「划线笔记」。点击顶部卡片盒图标打开。随手记无需 Chrome 或插件内 Token 配置。
- [Chrome 扩展 ZIP](https://github.com/rockbotcc/underline-notes/releases/download/0.5.0/underline-notes-chrome.zip)：Chrome 120+，解压后加载含 `manifest.json` 的文件夹。网页采集时在扩展设置配置思源连接。
- [Obsidian 插件 ZIP](https://github.com/rockbotcc/underline-notes/releases/download/0.5.0/underline-notes-obsidian.zip)：Obsidian 1.6+，继续提供本地 Markdown 卡片盒。

另附 Obsidian 更新文件 `main.js`、`manifest.json`、`styles.css`、`LICENSE`、`NOTICE` 及所有资产的 `SHA256SUMS.txt`。完整步骤见 [安装指南](https://github.com/rockbotcc/underline-notes/blob/0.5.0/INSTALL.md)。思源插件尚未上架集市。

## 升级与兼容

升级 Chrome 时沿用原安装目录并重新加载原扩展，保留扩展身份和本地资料。思源插件先停用、备份旧插件文件后更新，保留 `data/storage/petal/underline-notes/` 中的草稿和保存状态；启用后关闭旧卡片盒页签再打开。Obsidian 更新时保留 `data.json` 和其他用户文件。

思源实际验收环境为 3.8.10、macOS ARM64；其他系统和移动端尚未实机验收。思源版暂不提供双向修改浏览器摘录、附件上传、阅读足迹或 AI 自动标签；每日回顾不持久化完成进度，插件草稿面向单个活跃客户端。浏览器删除不删除思源副本。

本版功能已通过 61 项单元测试、独立官方思源内核与真实前端测试，以及 Chrome、Obsidian、flomo、图片笔记和自动标签回归。所有写入及故障注入测试均使用隔离工作空间。
